# 밴픽 자동 채우기 (윈도우)

롤 클라이언트의 밴픽 정보를 읽어서 정글 추천 페이지에 자동으로 채워요.
파이썬만 있으면 되고, 따로 설치할 건 없어요.

## 처음 한 번

1. 이 저장소를 받아요. GitHub 저장소 페이지에서 **Code → Download ZIP**을 누르고 원하는 곳에 압축을 풀어요.
2. 압축을 푼 폴더(`lol-champ-main`)를 엽니다.

## 실행 (더블클릭)

압축을 푼 폴더에 실행 파일이 3개 있어요.

| 파일 | 하는 일 |
|---|---|
| `바탕화면에 바로가기 만들기.bat` | **처음 한 번만** 더블클릭. 바탕화면에 "정글 픽 도우미" 바로가기가 생겨요 |
| `정글 픽 도우미.bat` | 실행. 브라우저에 추천 페이지가 열리고, 밴픽에 들어가면 자동으로 채워져요 |
| `정글 픽 도우미 (테스트).bat` | 롤 없이 가짜 밴픽으로 동작 확인 (6초마다 픽이 하나씩 진행) |

바로가기를 만든 뒤에는 바탕화면의 **정글 픽 도우미**만 더블클릭하면 돼요.
검은 명령 창은 작업 표시줄에 작게 내려간 채로 실행돼요. **끝내려면 그 창을 닫으면 돼요.**

압축 푼 폴더를 옮기면 바로가기가 안 맞으니, 옮긴 뒤 `바탕화면에 바로가기 만들기.bat`를 다시 실행하세요.

## 명령 창으로 실행하기

```
python tools\live_helper.py          실제 연결
python tools\live_helper.py --mock   테스트
```

## 알아둘 것

- **상대 포지션은 추정**이에요. 클라이언트가 상대 포지션을 알려주지 않아서 챔피언의 주 라인으로 배치해요. 틀리면 칸을 직접 고치세요.
- 직접 고치고 싶을 때는 화면의 **자동 채우기** 체크를 끄세요. 끄지 않으면 밴픽이 바뀔 때마다 다시 채워져요.
- 팀원이 아직 확정하지 않고 고민 중인 챔피언도 같이 채워져요.
- 밴픽 정보를 **읽기만** 해요. 클라이언트에 아무것도 보내지 않아요.

## 문제가 생기면

- "롤 클라이언트를 찾지 못했어요": 클라이언트가 켜져 있는지 확인하세요. 계속 안 되면 롤 설치 폴더를 직접 지정하세요.
  ```
  python tools\live_helper.py --league "E:\Games\League of Legends"
  ```
- 8840 포트를 다른 프로그램이 쓰고 있으면 `--port 8841`처럼 바꾸세요.
- 데이터를 새로 받았으면(저장소 업데이트) 다시 ZIP을 받거나 `git pull` 하세요.
