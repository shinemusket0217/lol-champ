## 항목

| 항목 | 설명 |
|---|---|
| 라인 | 주로 가는 라인 |
| 역할 | 조합에서 맡는 역할 |
| 딜_유형 | AD / AP / 혼합 (고정 피해 비중은 괄호로) |
| 딜_방식 | % 피해, 고정 피해, 지속 딜, 순간 폭딜, 평타 의존, 스킬 의존 등 |
| 탱킹_방식 | 체력형, 방어력형, 마저형, 회복형, 보호막형, 평타 카운터, 회피·무적형 (없으면 빈 목록) |
| 이동 | 돌진기, 도주기, 이동 속도 |
| 강한_시기 | 초반 / 중반 / 후반 |
| 약한_CC | 둔화, 침묵, 실명 등. 하드 CC는 data/cc_source.py 한 곳에만 적는다 |
| 강점, 약점 | 한 줄씩 |
| 정글_관점 | 우리 편일 때 갱 연계, 상대일 때 갱 난이도 |
| 메모 | 상성, 골드 구간 특이사항 등 |
| 검토 | 사용자가 확인하면 True |

주의: 최신 패치와 다를 수 있다. 리워크나 수치 변경이 보이면 고친다.
